## ⚡ Core Technologies

- **Framework:** [React 19](https://react.dev/) + [Vite](https://vitejs.dev/)
- **Language:** [TypeScript](https://www.typescriptlang.org/)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **Animations:** [GSAP](https://greensock.com/gsap/) & [Framer Motion](https://www.framer.com/motion/)
- **Visualizations:** [D3.js](https://d3js.org/)
- **Navigation:** [React Router 7](https://reactrouter.com/)

---

## 🛠️ System Architecture

El portafolio está estructurado como una aplicación distribuida en cuatro capas principales (Service Sectors):

1.  **01_HERO (SYS.READY):** Punto de entrada y visión general.
2.  **02_PORTFOLIO (SYS.GRID_VIEW):** Galería de proyectos con visualizaciones experimentales y detalles técnicos.
3.  **03_NETWORK_LOGIC (SYS.LOGIC_VIEW):** Visualización de habilidades técnicas y stack operativo.
4.  **04_CREDENTIALS (SYS.VALIDATION_LAYER):** Registros académicos y certificaciones de industria (OCI, GCP, Azure).

### Features:
- **Horizontal Navigation:** Experiencia de usuario cinemática gestionada por GSAP.
- **Interactive Background:** Rejilla de fondo dinámica y visualizaciones reactivas.
- **Project Modals:** Vistas detalladas con métricas de sistema, tech stack y enlaces externos.
- **Data-Driven UI:** Toda la información se gestiona a través de archivos de configuración centralizados en `src/data`.
- **Responsive System:** Optimización completa para dispositivos móviles sin comprometer la estética industrial.

## ⚙️ Getting Started

Para replicar este entorno de desarrollo localmente:

1. **Clonar el repositorio:**
   ```bash
   git clone <repository-url>
   ```

2. **Instalar dependencias:**
   ```bash
   npm install
   ```

3. **Iniciar servidor de desarrollo:**
   ```bash
   npm run dev
   ```

4. **Compilación para producción:**
   ```bash
   npm run build
   ```
